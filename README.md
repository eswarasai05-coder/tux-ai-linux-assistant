🛡️ Ethical Security

TUX-AI is designed for education and authorized security testing.

Before testing a system:

1. Get explicit permission.
2. Define the testing scope.
3. Use an authorized environment.
4. Perform testing safely.
5. Document your observations.
6. Report security issues responsibly.
7. Help fix the identified problem.

For practice, use:

- Your own computer
- Your own virtual machines
- Localhost
- Intentionally vulnerable training environments
- Authorized labs

Do not use security tools against systems, accounts, devices, networks, or applications without permission.

💻 Running Locally

TUX-AI is a web project.

Clone the repository:

git clone https://github.com/eswarasai05-coder/tux-ai-linux-assistant.git

Enter the project:

cd tux-ai-linux-assistant

You can then serve the files using a local web server.

For example, with Python:

python3 -m http.server 8000

Open:

http://localhost:8000
